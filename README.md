# Warehouse Inventory Optimization 

## 📌 Project Overview

Warehouse Inventory Optimization is a data-driven application designed to help optimize inventory management and support better warehouse decision-making.

The project analyzes inventory-related data and provides insights that can help identify stock requirements, inventory trends, and potential optimization opportunities.

## 🎯 Objectives

* Analyze warehouse inventory data
* Monitor stock levels
* Identify inventory trends
* Reduce the possibility of overstocking and understocking
* Support inventory planning and decision-making
* Provide an interactive dashboard for viewing results

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Open the project directory

```bash
cd Warehouse_Inventory_Optimization
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows:

```powershell
venv\Scripts\activate
```

### 5. Install the required packages

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit application

```bash
python -m streamlit run app.py
```

The application will open in the browser at:

```text
http://localhost:8501
```
